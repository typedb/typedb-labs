TypeDB Labs

Demonstration projects built on TypeDB. Every figure on every screen is read live from a TypeDB database, and each panel shows the TypeQL that produced it.

Project Apex

Deal intelligence for a fictional £2.4 billion acquisition: who is involved and how, what is being acquired through which chain of companies, and which contractual deadline breaks if a regulator takes 61 more days.

NoodleLab Visual Explorer

An original electric vehicle that separates into an exploded assembly. Select a part to ask TypeDB what it is, what it connects to, which systems it serves and what stops working if it fails.
Open source under Apache-2.0 on GitHub. Everything in these demonstrations is fictional.
